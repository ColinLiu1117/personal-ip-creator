# 调用已有 IP 创作

顺序：指定名称 → 读取正式设定 → 补齐本次必要信息 → 设计场景与选择参考 → 生成 → 单张／整组验收 → 保存。

## 读取与需求

按 storage.md 查名称和版本。名称遗漏则询问；找不到则说明并提供已登记名称，不用其他角色代替。只有草稿时说明还需完成设定，不将其冒充正式IP。

按需补充用途、主题重点、数量、尺寸或比例、准确文案；不重做IP定位访谈。正文、海报、封面必须有用户给出的尺寸或比例，“横版”不足以推定16:9。头像默认方形并留圆形裁切安全区，贴纸透明。用户只给比例时记录为比例要求，不声称已承诺精确像素。

## 参考选择

| 任务 | 优先参考 |
| --- | --- |
| 头像 | 面部、发型、画风 |
| 全身动作 | 四视图、比例、服装和相关动作 |
| 讲解场景 | 身份、道具互动和构图 |
| 表情贴纸 | 脸部、表情表现和装饰样式 |

正式设定约束身份，应用参考只影响标注用途。缺少动作参考时依据正式设定设计，不要求补齐一套动作库。新动作参考不能把外部角色的比例和衣服带进来。

## 可绘制场景

确定表达重点、人物行为、参与者、物件状态与接触关系、视线、情绪、构图和文字位置。例如AI整理笔记要分清是展示前后变化还是步骤；信息足够时自行具体化，不问每个细节。

内容与情绪强度分开：教程以清楚适度为主，日常互动可加强情绪，贴纸可更夸张。遵循用户要求与角色性格，不固定档位配额，不每次要求选档。道具和家具适应既定身体比例，不为了够到物件拉长四肢。

提示词表达可见画面：身份与比例基准＋本次有效外观＋动作互动＋情绪＋构图背景＋准确文字与样式＋输出要求。移除被明确临时替换的默认外观要求。内部路径、配置键、审核编号不作为画面文案。

正文、标题、对话和HI等短语采用用户提供或已确认内容，准确保留文字及必要换行。不得自动添加长文或标题。问号、汗滴、闪光等非文字符号可适量设计；字形、气泡与强调色可借鉴已有样式，不复制参考文案，不继承无关构图。装饰服务于当前情绪。

## 确认边界

- 明确单张：内部形成方案后直接生成，无额外方案审批。
- 关键歧义会改变结果：先确认方向。
- 批量：确认清单、尺寸和文案，生成样张获认可后继续。只有用户明确允许复用已认可风格并跳过样张时才跳过。
- 每张独立作品单独交付，联系表辅助；用户要求多格漫画则作为整体布局处理。

按 quality.md 检查。修改仅针对反馈，保留未受影响的已确认内容，同时检查生成结果是否仍保持它们。记录本次使用的IP版本和临时变化；普通作品不自动晋升应用参考。
