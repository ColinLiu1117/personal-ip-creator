# 图像执行与验收

## 工具与实际文件

使用当前可用的图像生成／编辑工具及其适用规则。编辑已有图时传实际目标和必要身份参考，先查看本地图片。不假设工具支持指定像素、透明度、批量或局部编辑；按实际能力执行，限制影响需求时说明。

结果必须有可读取的真实文件，保存至资产库。若只有显示结果而无法保存文件，说明归档未完成，不登记为可复用正式资产。保留原始候选；生成记录不能填入不存在的路径或伪造提供方信息。

## 检查维度

技术：解码检查宽高、格式和实际比例；分别记录用户要求、提供方实际输出及最终文件。精确像素要求须核对。透明背景需实际检查透明区域及边缘，不把白底、棋盘格或仅有alpha通道视为满足。必要时使用可用的图像检查库；没有能力验证就记未验证，不写通过。不擅自拉伸、裁切以掩盖尺寸不符。

视觉：实际查看成图，与正式参考比较身份、画风、比例、服装及标志物位置；检查肢体、手势、物件接触、主题表达、文字准确性、头脚与构图裁切、透明边缘。中性全身可辅助测量头身比；遮挡、半身、透视图不编造完整比例。测量数值需要说明依据，不能从提示词直接得出。

整组：身份与外观一致，各张情绪或内容可区分，避免只换文字却重复动作；按预期使用尺度检查可读性。四视图检查各朝向与结构一致。

## 修正与交付

文字错漏、身份漂移、明显肢体问题、尺寸不符是明确缺陷；轻微表情差异不必自动重画。针对明确问题最多两轮自动修正，保留未受影响的既定要求；局部编辑后也检查整张图。超出预算或仍有问题时报告未解决项，让用户决定下一步。

文件路径、元数据等归档问题优先修复归档，不因此自动重生成图片。记录实际观察和验证方法；未检查、未通过和用户尚未确认分开，不把技术通过当作用户审美批准。交付实际结果与文件链接，失败候选单列，不填充成正式作品。
