# 创建、续做与永久更新

## 访谈

先读取已给出的要求和已有草稿，一次围绕一个关键问题交流，推荐选项并给理由。按缺口询问，下面是覆盖范围，不是逐项必答问卷：

- IP名称、面向谁、分享什么、希望帮助用户做什么。
- 角色关系与性格：例如探索同伴、温暖耐心；转成遇到疑问、讲解、失败时的具体表现习惯。
- 预期使用场景、动画化方向、必须保留与明确不要的外观。
- 创作来源：个人外貌转化或原创。前者需要照片提取可见个人特征；照片未提供时保留待补项，不伪称已提取。原创不要求照片。

参考图可为空，直接访谈。存在参考图时记录用户采用的情绪、气质、动作、比例、颜色、记忆点和构图，不复制原人物、服装或脸部细节。方案由访谈结果＋可选参考特征＋适用的个人外貌特征构成。

## 预览

用户无具体比例要求时采用 semi-chibi：目标约2.8头身，参考区间2.695–2.995。大头、紧凑躯干、适度缩短且圆润的四肢。该范围是本项目预设，不是通用审美标准，也不是年龄设定。

不强制问比例。用户说更Q、更修长或给出具体数值时优先调整；有实质歧义才追问。用户改变比例后按实际确认结果保存自定义目标和描述，不继续套原范围。不能自动改变年龄感、身份或服装。

方向明确先做一张预览；关键方向难判断时可做2–3个只改变关键变量的比较。预览须便于判断造型、动画化程度和身体比例。用户确认后保存参考图、目标及适用范围、躯干和四肢特征、脸部简化程度。比例测量不能代替视觉确认；不得拉伸成图凑数。

## 正式设定

风格和外貌确认后交付：

1. 角色档案：定位、受众、来源、性格与表现习惯。
2. 视觉规范：身份特征、默认外观、允许的本次变化、比例及配色；身体左右按角色自身定义。
3. 中性正常站姿四视图：正、背、左侧、右侧，完整头脚，统一比例和服装、平视弱透视、头顶与鞋底对齐。手臂自然放置并便于看清结构，无欢迎或讲解等明显动作倾向。标明侧面朝向，避免左右混淆。
4. 角色确有标志性耳机、首饰、图案等时，给出细节设定图及形状、尺寸关系、颜色、材质、位置、佩戴规则；没有则记不适用，不凭空造一个。四视图可见性与细节图一致，被合理遮挡时不移位补显。
5. 配置与资产索引，附便于完整确认的设定总览；独立原图仍保留。

检查整体一致性后请用户确认完整资料，而不是凭预览通过就发布正式版本。记录确认范围与原话、相关版本和时间，按 storage.md 发布，然后停止。未通过则继续草稿。

独立颜色材质页、复杂服装结构页、面部发型放大页、四视图比例标注目前只是按需求可选的补充，不是已批准的统一必交项。不能因此自动生成整套表情、日常状态或动作库。

## 续做与更新

恢复草稿的已确认结论、待答问题和当前阶段，不重复开场访谈。永久更新以旧正式版为来源建立新草稿，评估并同步受影响的规范、四视图、细节与配置，完整确认后再更换默认版本。旧版本及关联作品保留。临时服装或场景按内容流程处理，不建立永久设定修改。
