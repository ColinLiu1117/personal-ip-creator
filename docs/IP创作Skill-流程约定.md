# 通用 IP 创作 Skill：流程约定

更新日期：2026-10-22

状态：已整理为 `skills/personal-ip-creator/` 技能包。本文件保留需求与确认依据；运行规则见技能入口及其 references，使用方式见同目录的《个人IP创作技能-使用说明.md》。后续需求变化应同步维护流程约定与对应运行文档。待确认建议单列，不作为执行要求。既有橙子专用技能和资产保持原状，新建角色的默认比例不追溯覆盖已确认角色。

## 1. 范围与入口

- 初版聚焦人类角色、动画／Q 版、静态内容，保留未来扩展风格的可能；暂不支持外部已有 IP 导入。
- 支持创建多个 IP，以名称区分，每个 IP 使用独立目录；后续调用必须指定 IP 名称，不猜测默认角色。
- 两个独立环节：创建并确认 IP 设定；用户另行发起基于该 IP 的内容生成。完成设定后停止，不自动生成头像、表情包或演示配图。
- 先检查用户已有信息，再补齐缺失内容。自适应访谈内置于流程，不以安装 grill-me 为前提。
- 完整出图需要可用的图像生成能力；工具不可用时如实说明，不把文字方案视为已完成的图像资产。

## 2. 创建阶段：输入与访谈

1. 确定 IP 名称并检查是否重名。重名时让用户选择继续草稿、更新原 IP 或使用新名称，不覆盖或自动加编号。
2. 参考图可选。提取用户希望借鉴的情绪、气质、动作、比例、颜色、视觉记忆点和构图，不复制原角色、服装与脸部细节。
3. 根据已有信息逐个问题补齐定位、受众、性格、用途及外观要求，必要时提供有理由的推荐，不重复已回答的问题。
4. 确认角色来源：个人外貌转化或原创。前者由用户提供照片提取个人特征；后者无需照片。可选参考图、访谈结论和适用的个人特征共同构成方案。
5. 把性格转成简短表现习惯，说明角色遇到疑问、讲解或失败时如何反应，供后续内容创作使用。

## 3. 参考资料的职责与冲突

- 每份参考记录来源、用途、采用的特征及不采用的内容。按需区分个人外貌、身份、画风、比例、动作、构图、服装、背景、文字样式等职责。
- 参考只能影响指定部分：动作参考不改变身体比例，画风参考不带入原服装，文字样式参考不带入原文案。
- 已确认正式设定约束角色身份；本次明确要求可调整允许变化的字段。若本次要求实质改变身份，先明确是更新设定还是其他需求，不能自行混合或覆盖。
- 仅选择本次有用的参考，避免把整个资产库无差别输入。
- 将实际采用的参考保存到对应 IP 的资产体系中，不依赖剪贴板或临时路径。

## 4. 预览比例：已确认的默认规则

- 用户没有具体要求时，采用参考仓库的 `semi-chibi`：约 **2.8 头身**，参考区间 **2.695–2.995 头身**。
- 视觉特征为大头、紧凑躯干、适度缩短且圆润的四肢。该区间是项目预设，不是所有 Q 版角色的通用标准。
- 不把比例选择作为必答问题；访谈或预览反馈中用户提出更 Q、更修长或具体比例时，优先按用户要求调整。歧义会影响结果时再针对性确认。
- Q 化只调整身体比例，不自动改变年龄感、身份特征或服装。
- 方向明确时先出一个预览；确有关键方向歧义时，可做 2–3 个聚焦单一变量的比较，不默认生成所有比例版本。
- 用户确认预览后，保存该 IP 的比例目标、适用范围、躯干与四肢描述，以及认可的视觉基准。用户调整后的比例不再套用原默认区间。
- 数值辅助视觉检查，不以压缩或拉伸图片凑比例。完整头身比主要用于适合测量的中性全身图；半身、遮挡及透视画面不机械套用，也不编造测量结果。
- 四视图和后续内容沿用已确认的 IP 基准，不能在每次调用时重新重置为 2.8 头身。动作、道具与家具适应该比例，避免为接触物件而拉长角色。

来源：[比例规则](https://github.com/ColinLiu1117/deepseek-whalechan/blob/main/skills/whalechan-image-character/references/form-profiles.md)。上述默认值已在本次讨论确认，未来上游变更不自动改写本地规则。

## 5. 正式设定与交付

预览风格和外观确认后，再制作完整设定：

1. 角色档案：定位、受众、性格、表现习惯与角色来源。
2. 视觉规范：比例基准、外貌、配色及固定与可变规则。
3. 中性站姿四视图：正面、背面、左侧、右侧；完整身体、正常站立，无明显动作倾向。统一比例与视角，头顶和脚底对齐，检查各视图结构一致性。
4. 标志性内容细节：角色确有耳机、首饰、图案等标志性物件时，明确形状、颜色、材质、大小、位置和佩戴方式，必要时补充细节设定图；不强行添加物件。
5. 调用配置与资产索引：名称、版本、状态、规则、参考用途和文件路径。

外观分为三层：

- 身份特征：持续保持，永久修改需更新设定。
- 默认外观：常用服装、配色及配件；符合允许变化规则的临时替换仅影响当前作品。
- 本次变化：动作、场景、道具和已明确的临时外观要求。

组合提示词时，临时替换字段应移除相冲突的默认要求，不能同时要求两套服装。标志性特征被合理遮挡时不移动位置补显。

用户确认完整设定资料后，配置和资产一起正式保存；此阶段结束。未确认内容保留草稿，不能标记为正式。

## 6. 基于已有 IP 生成内容

执行顺序：指定 IP → 读取正式设定 → 补齐本次必要信息 → 形成场景方案并选择参考 → 生成 → 单张／整组验收 → 保存作品与记录。

### 6.1 读取设定与补齐需求

- 用户指定 IP 名称后，读取正式版本及适用参考；支持头像、表情、日常配图、正文配图、海报、封面及其他静态内容。
- 正文配图、海报、封面等由用户提供尺寸或比例，不默认 16:9。头像默认方形并考虑圆形裁切安全区；贴纸使用透明背景。
- 根据用户已给信息补齐本次必要的用途、表达重点、数量、尺寸和准确文案；只询问会实质改变结果的缺失信息，不重新进行完整的 IP 创建访谈。

### 6.2 按任务选择参考

正式设定始终约束身份，应用参考按需调用，不把全部资产无差别输入。

| 创作需求 | 优先参考内容 |
| --- | --- |
| 头像 | 面部特征、发型、画风 |
| 全身动作 | 四视图、比例、服装、相关动作参考 |
| 讲解配图 | 身份设定、道具互动、场景构图 |
| 表情贴纸 | 面部特征、已认可的表情表现、装饰样式 |

缺少某个动作或场景的应用参考时，可以依据正式设定设计新内容，不要求用户先补出整套动作库。每份参考仍遵守第 3 节的职责与冲突规则。

### 6.3 场景方案与表现强度

- 把主题转成可绘制场景：人物做什么、与什么物件互动、视线与手势指向哪里、情绪如何体现、文字出现在哪里。角色应参与表达内容。
- 区分内容重点与表现方式。例如“AI 整理学习笔记”可以突出整理前后变化或操作步骤；系统依据已有信息设计，只有不同解释会明显改变作品时才询问用户。
- 内容方向与情绪强度分别决定。教程正文配图通常表情清晰、动作适度并突出知识；日常互动配图可加强情绪和互动细节；表情贴纸可采用更明显的表情与动作夸张。
- 根据用途推荐表现强度，不要求用户每次选择档位，也不照搬参考仓库的档位配额。用户明确要求优先，同时保持该 IP 已确认的身份特征和性格约束。
- 绘图提示词以具体可见内容为主，不混入配置路径、审核编号等内部执行信息。

### 6.4 文字、情绪装饰与构图

- 文字采用用户提供或已确认的准确内容，不擅自添加标题或长段文字。非文字情绪符号可适量使用；HI 等短语需事先确认。
- 问号、汗滴、闪光和动作线等符号应帮助表达当前情绪，不作为无关填充装饰。
- 气泡、文字强调色和字形处理可参考该 IP 已认可的视觉语言，只借用样式，不复制示例文案。
- 布局与人物位置服务于当前内容，文字样式参考不自动决定整张图的构图。

### 6.5 确认与生成

- 明确的单张需求直接生成，场景方案可在内部完成，不为每张图强制增加方案审批。
- 存在会明显改变结果的关键歧义时，先确认方向，再生成。
- 批量先确认清单、尺寸和文案，样张认可后再继续。用户明确允许复用已认可风格并跳过样张时按其要求执行。
- 独立作品分别交付，联系表仅辅助浏览；用户明确要求漫画或多格板时按整体构图处理。
- 生成后按第 7 节检查，按第 8 节保存作品与记录；作品不会自动晋升为应用参考。

## 7. 检查与修正

- 技术检查：文件可读、实际尺寸和比例符合要求、需要透明背景时检查真实透明度，而非仅确认有透明通道。
- 分别记录用户要求尺寸、工具输出尺寸和最终交付尺寸。工具无法满足时说明限制，不因提示词写了尺寸就判定满足，也不擅自裁切或拉伸来掩盖不符。
- 视觉检查：身份、比例、服装与标志物、肢体与道具接触、内容表达、文案、完整性及边缘质量。
- 批量追加一致性、重复程度与整体可读性检查。
- 对成组表情等内容，检查各张情绪能否区分、是否仅更换文字而重复动作，以及缩小到预期使用尺度后是否仍然清楚。
- 区分需要修正的实质错误与可接受的小差异；仅对明确问题定向修正，最多两轮自动修正。审美偏好交由用户反馈，不无限重画。
- 修改围绕用户反馈或已发现的具体缺陷，保留已确认且不受本次修改影响的内容。例如“疑惑感不够”优先调整眉眼、手势和问号表现，不擅自更换服装、配色或构图。生成后仍须核对这些保留项是否发生漂移。
- 局部编辑后重新检查整张图；如实报告未解决问题，不把失败候选混入正式交付，也不编造已检查或已通过记录。

## 8. 保存、版本与参考晋升

- 首次确定资产库位置并记录；每个 IP 独立目录，通用流程规则与角色配置分开维护。
- **正式设定库**：用户确认的身份、视觉规范、四视图、标志性细节及调用配置，回答角色长什么样。
- **应用参考库**：用户明确认可为后续参考的表情、动作、道具互动、场景或文字装饰样式；每项标注可参考的用途，不能覆盖正式身份规则。
- **普通作品**：默认保存生成作品及记录。认可作品本身不等于同意把它作为长期参考；用户明确同意后才加入应用参考库。
- 草稿与候选单独保存，支持续做；正式资产不能被草稿覆盖。
- 每次生成记录 IP 版本、本次要求、使用参考、提示词、生成结果与检查结论。保留正式参考文件，避免仅留下临时链接。
- 永久修改建立新版本草稿，同步相关规范、设定图和配置，完整确认后才成为默认正式版本；旧版本和旧作品的版本关联保留。
- 提供设定总览或批量联系表方便比较，独立原图仍须保存；完整离线图库系统不作为初版前提。

## 9. 尚未确认的新增资产建议

下列是仓库比较后提出的建议，用户已确认保存机制，但尚未逐项确认这些内容全部成为首次创建的必交资产：

- 独立的颜色／材质规范页。
- 复杂服装的层次与结构细节页。
- 面部与发型放大细节图。
- 比例标注是否整合进四视图版面。

表情、动作、日常状态、道具互动和文字装饰模板可由后续用户发起的内容生成逐步积累，不能因此在创建结束后自动追加生成任务。非人类身体部位、多比例全套资产、辅助角色库、多模型调度和复杂并行生成不纳入当前初版要求。
