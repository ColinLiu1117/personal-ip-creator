# 个人 IP 创作技能使用说明

技能名：`personal-ip-creator`。工作区源包：`skills/personal-ip-creator/`。采用自适应访谈创建动画／Q版人类角色，并按名称调用角色生成静态内容。

## 如何使用

创建角色：

> 使用 $personal-ip-creator，帮我创建一个名为“小禾”的个人IP，面向刚开始学习AI的上班族。采用原创角色，没有参考图。

按照片转化：

> 使用 $personal-ip-creator，创建名为“小禾”的IP，按我的照片保留个人特征；我另外提供的图片只参考画风。

调用内容（仅适用于库中已完成设定的角色）：

> 使用 $personal-ip-creator，用“小禾”画一张16:9的配图，表现AI整理学习笔记前后的变化，不加文字。

批量创作：

> 使用 $personal-ip-creator，用“小禾”做六张透明背景表情贴纸，表达欢迎、疑问、思考、发现、尝试、成功，不加文字。先确认清单并看样张。

更新设定：

> 使用 $personal-ip-creator，把“小禾”的默认服装永久改为浅绿色，保留旧版本，更新完整设定供我确认。

这些是调用示例，不会随安装创建“小禾”。本技能不自动导入已有橙子资产，也不改写橙子专用技能。初版暂不支持外部IP导入。

## 交付与保存

首次运行确认资产库位置，将位置保存到项目的personal-ip-library.json；实际角色配置、照片、参考与作品放在该库，不放进技能目录。多个IP按名称管理。

创建交付档案、视觉规范、中性站姿四视图、适用的标志物细节图和调用配置；完整确认后停止。默认新角色约2.8头身，用户要求优先，确认后沿用自己的比例基准。后续头像、表情与配图须另行发起。

普通作品、应用参考、正式设定分开。只有明确同意“作为后续参考”，作品才进入应用参考库。永久修改保留旧版本，作品记录生成时使用的版本。

正文配图、封面、海报请给尺寸或比例。明确单张直接生成；批量先确认清单和样张，用户明确授权时可跳过复用风格的样张。
